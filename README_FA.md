# ATOM — ساختار ماده

یک وب‌سایت آموزشی تعاملی دربارهٔ اتم، ساختهٔ امیر سعید دهقان.

## امکانات

- نمایش نمونه‌های سه‌بعدی از چگالی احتمال اوربیتال‌های هیدروژن شامل s، p، d و f، همراه با چرخش، بزرگ‌نمایی و توقف حرکت.
- جدول تناوبی ۱۱۸ عنصر با جست‌وجو و اطلاعات پایه و آرایش الکترونی.
- معرفی هشت ایزوتوپ، مرور و مقایسهٔ نظریه‌های اتمی و محاسبه‌گر طیف هیدروژن.

## نکات و محدودیت‌ها

رنگ اوربیتال نشانهٔ علامت تابع موج است و شکل‌ها عکس واقعی اتم نیستند. محاسبهٔ طیف بر پایهٔ تقریب هیدروژن است. این پروژه هنوز همهٔ امکانات پرامپت اولیه را ندارد: انتخاب عنصر مدل کوانتومی را تغییر نمی‌دهد، مقایسهٔ مدل‌های تاریخی با نمادهای مفهومی انجام می‌شود و ابزارهایی مانند تور آموزشی، آزمون تعاملی و مدل‌های سه‌بعدی آماده هنوز اضافه نشده‌اند.

## اجرا

در پوشهٔ پروژه `npm start` را اجرا و نشانی `http://localhost:8000` را باز کنید. برای بررسی داده‌ها `npm test` را اجرا کنید. منابع علمی و مجوز مجموعه‌داده در فایل README انگلیسی آمده‌اند.
