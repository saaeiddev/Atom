# ATOM — ساختار ماده

پروژه‌ای آموزشی از امیر سعید دهقان. این نسخه اولیه است و هنوز تمام امکانات درخواستی را شامل نمی‌شود.

## امکانات فعلی

- نمایش نمونه‌های نقطه‌ای از چگالی احتمال اوربیتال‌های هیدروژن 1s، 2s، 2p و 3d با WebGL؛ رنگ‌ها نشانهٔ علامت تابع موج هستند، نه رنگ واقعی الکترون.
- مرور کوتاه تاریخ نظریه‌های اتمی.
- محاسبهٔ تقریبی طول موج، انرژی و بسامد فوتون برای گذارهای هیدروژن.

## اجرا

در پوشهٔ پروژه دستور `python3 -m http.server 8000` را اجرا کنید و نشانی `http://localhost:8000` را در مرورگر باز کنید.

## محدودیت‌ها

جدول تناوبی کامل، آزمایشگاه ایزوتوپ، مدل‌های تاریخی سه‌بعدی تعاملی، اوربیتال f، حالت مقایسه و سایر بخش‌های پیشرفته هنوز ساخته نشده‌اند. رندر WebGL در مرورگر آزمایشی اولیه در دسترس نبود و اعتبارسنجی علمی و تصویری بیشتر لازم است. منابع علمی در README انگلیسی آمده‌اند.
